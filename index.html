HOW I THINK

Problem → Insight → Decision → Product → Outcome.

Start with the user's decision.

What is the user actually trying to understand, decide or change? The answer shapes the product before the technology does.

Make complexity legible.

Separate facts, derived signals and interpretation so a user can understand why the system reached a conclusion.

Use AI where it adds leverage.

Keep financial and business calculations deterministic. Use AI for investigation, synthesis, reasoning and explanation.

Design for the next action.

A useful answer changes what a user can do next — investigate, approve, challenge, resolve or act.

PRODUCT QUESTIONS I LIKE

Where does intelligence create the most leverage?

When should an agent act?

What evidence and confidence should exist before a system recommends, asks for approval, or acts on a user's behalf?

How should AI explain a decision?

How do we make probabilistic systems understandable without pretending there is more certainty than the data supports?

What should stay deterministic?

Where should product rules and calculations remain explicit, while AI handles the messy reasoning around them?
