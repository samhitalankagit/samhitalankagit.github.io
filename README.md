Product work across enterprise AI, manufacturing, supply chain and financial services.

## Featured project

CostLens is the working prototype: an AI manufacturing investigation experience that combines structured data, deterministic analysis tools and an LLM explanation layer.

## AI / ML work

- **Explain:** LLM + structured enterprise data for manufacturing cost and WIP investigation.
- **Investigate:** agents + RAG + knowledge retrieval for Cost Processor troubleshooting.
- **Predict & decide:** machine-learning models for real-time fraud detection.

The codebase keeps the existing static portfolio pages intact and adds `costlens-api/` for the optional server-side AI layer.
