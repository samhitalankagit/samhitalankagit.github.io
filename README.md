# Samhita Lanka — AI Product Portfolio

Static portfolio site for GitHub Pages.

## Public-safety rule
Do not add Oracle internal documents, screenshots, code, prompts, datasets, recordings, architecture, or confidential customer information. The flagship project is a public, de-identified prototype inspired by the general class of enterprise problems Samhita has worked on.

## Files
- `index.html` — portfolio homepage
- `styles.css` — site styling
- `projects/cost-investigation.html` — flagship case-study page

## Publish with GitHub Pages
1. Create a public repository named `<your-github-username>.github.io`.
2. Upload these files to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Save, then open `https://<your-github-username>.github.io`.

GitHub notes that Pages changes can take a few minutes to publish.
